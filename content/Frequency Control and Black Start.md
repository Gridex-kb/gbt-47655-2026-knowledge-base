# 1차 주파수조정과 블랙스타트

## 1차 주파수조정

| 항목 | 범위·한계 |
|---|---|
| 주파수 데드밴드 | ±0.01~±0.15 Hz |
| 드룹 | 2~10% |
| 지연시간 | ≤50 ms |
| 상승시간 | ≤500 ms |
| 정정시간 | ≤1 s |
| 유효전력 조정오차 | ≤±2% Pn |
| 오버슈트 | ≤20% |

시험 §5.12는 0.001 Hz 단계로 데드밴드를 찾고, ±0.05, ±0.15, ±0.2 Hz의 주파수 계단을 가해 전력응답과 동특성을 기록한다. 정상상태에서 유효전력을 공급할 수 있는 대상에만 적용된다.

## 블랙스타트

블랙스타트 능력을 주장하는 설비는 계통전압·주파수 형성, 정상·충격부하를 위한 전력과 에너지, 변압기·선로 투입 시 과전류 내량, 소프트스타트, 전력균형 유지 능력을 갖춰야 한다. 단계별 부하 투입 시 저항부하 전압변동 ±5%, 유도전동기 투입 전압강하 15% 이내·500 ms 이내 복구, 민감부하 전환중단 10 ms 이내가 제시된다.
