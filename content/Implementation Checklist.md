# 도입·조달·검증 체크리스트

이 체크리스트는 표준 조항을 프로젝트 업무로 변환한 해석 자료다.

## 요구사항 정의

- [ ] 적합성 주장 경계를 단품·발전단지·복합시스템 중 하나로 명시
- [ ] 장비 유형과 유효·무효전력 운전범위 명시
- [ ] 목표 관성시간상수와 관성응답 에너지 명시
- [ ] 적용 OSCR 범위와 계통/도서 운전 시나리오 확정
- [ ] 블랙스타트 적용 여부와 대상 부하 정의
- [ ] U-I 곡선, 과부하 배수와 지속시간 제출 요구

## 시험 설계

- [ ] 실시간 시뮬레이터와 현장 제어·보호 시스템의 동일성 입증
- [ ] 네 OSCR 구간과 최대·최소 운전점 시험행렬 작성
- [ ] 자연응답 측정과 보조제어 해제 조건 명시
- [ ] 보호 미동작, 원시파형, 계산식, 판정조항을 시험성적서에 연결
- [ ] LVRT/HVRT 연속조건과 고장 후 전력복구 동시 검증
- [ ] 임피던스 스캔 데이터와 계통 임피던스 비교 책임자 지정

## 계약·운영

- [ ] GB/T 권고표준을 계약상 의무로 채택하는지 명시
- [ ] 발주자 결정 항목과 공급자 보증 항목 구분
- [ ] 펌웨어·제어정수 변경 시 재시험 범위 정의
- [ ] 시행일 이후 공식 상태와 개정 여부 재확인
