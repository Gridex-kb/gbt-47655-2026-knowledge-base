# 구성망 핵심 용어

표준 §3.1은 구성망을 전압원 특성을 가진 장비·시스템이 필요한 관성, 단락용량, 유효전력 및/또는 무효전력을 제공하고 정상·동적·과도 조건에서 전력 균형과 계통 안정운전을 지지하는 능력으로 정의한다. 전압원 특성은 내부 기전력의 크기와 주파수를 자율적으로 형성·유지하는 능력을 의미한다.

| 용어 | 표준상 의미의 요약 | 조항 |
|---|---|---|
| 관성응답 전력 | 접속점 주파수 변화율에 자연응답하여 방출·흡수하는 유효전력 | §3.2 |
| 관성응답 에너지 | 주파수 변화율 자연응답 과정에서 방출·흡수하는 에너지 | §3.3 |
| 위상점프 응답전력 | 접속점 전압 위상점프에 자연응답하는 유효전력 | §3.4 |
| 감쇠응답 전력 | 교류계통 전력진동에 응답하는 유효전력 | §3.5 |
| 1차 주파수응답 전력 | 계통주파수와 목표주파수 편차에 응답하는 유효전력 | §3.6 |
| 총 주파수응답 전력 | 관성·감쇠·1차 주파수응답 전력의 합 | §3.7 |
| 전압변화 응답전류 | 접속점 전압크기 변화에 자연응답하는 전류 | §3.9 |
| OSCR | 접속점 단락용량을 실제 운전전력으로 나눈 값 | §3.12 |

여기서 자연응답은 외부 보조제어 동작 이전의 고유 응답을 가리킨다. 따라서 빠른 AGC나 별도 주파수 제어만으로 관성응답을 대체했다고 해석해서는 안 된다.
