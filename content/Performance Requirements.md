# 성능 요구사항 지도

| 영역 | 핵심 내용 | 조항 |
|---|---|---|
| 계통접속 적응성 | 약계통·도서계통·전환, 주파수·위상·전압 변화, LVRT/HVRT | §4.1 |
| 관성응답 | 5 ms 이내 자연응답, 관성시간상수와 에너지 | §4.2 |
| 동적 전압응답 | 5 ms 이내 자연응답 전류, 내부전압 제어 | §4.3 |
| 계단응답 | 직류송전·ESS의 유효전력 및 무효전력 응답 | §4.4 |
| 감쇠 | 저주파와 광대역 진동 억제 | §4.5 |
| 고장 후 복구 | 유·무효전력 복구율 | §4.6 |
| 1차 주파수조정 | 드룹, 데드밴드, 응답시간과 오차 | §4.7 |
| 블랙스타트 | 계통 형성, 부하 투입, 과전압·돌입전류 관리 | §4.8 |
| 과부하 | 설비별 과부하 능력과 U-I 특성 제공 | §4.9 |
| 전력품질 | 전압편차, 플리커, 고조파, 간고조파, 불평형 | §4.10 |

표준 적합성 검토에서는 성능 요구조항과 해당 시험의 목적·절차·판정기준을 짝지어야 한다. 예를 들어 관성응답 요구는 §4.2, 시험은 §5.3이며, 광대역 진동 감쇠 요구는 §4.5, 시험은 §5.10이다.
